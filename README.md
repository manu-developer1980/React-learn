# Ruta React — 8 proyectos (portfolio)

Repo de la ruta práctica de **React frontend** (sin calendario fijo): guía de proyectos, plantilla de briefing y reglas de acompañamiento en `.cursor/rules/`.

## Contenido

| Archivo | Descripción |
|---------|-------------|
| [GUIA_8_PROYECTOS.md](./GUIA_8_PROYECTOS.md) | Orden sugerido, MVPs y checklists |
| [PROJECT_BRIEF_TEMPLATE.md](./PROJECT_BRIEF_TEMPLATE.md) | Plantilla de brief + edge cases antes de codificar |
| `.cursor/rules/Teacher.md` | Contexto y metodología (rol de la IA / alumno) |

Cada proyecto vivirá en su carpeta (`p01-dashboard`, etc.) según avances.

## Uso rápido

1. Elige un proyecto en la guía.
2. Copia `PROJECT_BRIEF_TEMPLATE.md` → `BRIEF.md` dentro de la carpeta del proyecto.
3. Cierra el brief (planificación + edge cases) antes de implementar el MVP.
